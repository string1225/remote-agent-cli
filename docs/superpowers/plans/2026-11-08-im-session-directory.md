# IM 收件人名称与会话映射

用户需要本机 Agent 发现已有 IM 会话，按真实姓名/群名选择收件人，未指明对象或发生重名时询问。实现沿用账号鉴权及 139 WebSocket，不开放聊天正文、通讯录或通用会话控制。查询复用当前机器人 fingerprint 的已持久化 route，返回客户端、项目、机器人、私聊/群聊、peerName、nameKnown 和真实 sessionId；同名不合并，未知名称不推测，活动列表按 50 条分页。

MCP 增加只读 `list_im_sessions`，可指定 clientId/projectId/search/cursor。服务端仅增加 `channels.sessions` 白名单，客户端以独立处理器返回最少元数据，不启动机器人或任务系统。Qoder MCP 白名单同步。发送继续使用明确 ID；skill 和工具描述指导用户意图消歧，不重复确认明确唯一的对象，也不改变正常 IM 回答的返回方式。
