# Unified Codex platform implementation plan

> 历史实施与部署记录。2026-10-23 已将对应代码汇入 `main`；后续目标和验收以 [project-goals.md](../../project-goals.md) 为准，开发直接使用 `main`。文中 winget、用户登录自启动等描述反映当时实现。

**Goal:** provide account-controlled Codex proxy access, a persistent local CLI independent of enrollment, optional remote service control and cross-platform Codex CLI/App setup alongside the existing remote workbench.

**Architecture:** keep the existing model gateway, old OpenAI routes/tokens and OAuth state; add a fixed-loopback, token-authenticated inference adapter to this Go server. Account and token ownership reside in bbolt under immutable IDs. A local Go setup helper installs Codex and merges private TOML/profile configuration; shell installers call the same helper. Remote execution continues over DataChannel, separately from the HTTPS model flow.

**Tech Stack:** Go 1.26, bbolt, bcrypt, embedded HTML/CSS/JavaScript, TOML v2, PowerShell/Bash.
