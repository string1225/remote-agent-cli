# 项目目标、现状与验收

基线：2026-10-25。服务器管理账号、设备注册、保活、网页入口和业务中转；客户端负责实际工作和本地数据。Windows 正式交付 MSI + Windows Service，开机运行、退出登录仍在线。需求中的 `code` 指 **Qoder**。所有开发直接提交并推送 `main`。

## 系统关系

账号 → 多个客户端 → 多个项目 → Web 会话、IM 私聊/群聊会话、置顶 SaySo。项目是工作目录与 Codex/Qoder 执行器；新增项目自动创建一个 Web 会话，重试复用原项目。客户端使用可识别的 Windows/macOS/Linux 图标，绿色实心在线、灰色空心离线并显示文字；右键或更多菜单可重命名和修复绑定。聊天使用安全 Markdown，输入框固定底部，默认 Enter 发送、Shift+Enter 换行。

网页按账号、客户端、项目、会话隔离实时保存草稿和有界历史缓存；先显示缓存，再以客户端历史校对，未发送草稿独立保留。支持后台执行的客户端接收任务后，网页可切换或关闭，返回时加载更新；不同会话并发，同一会话顺序执行。每轮执行上限为 2 小时，超时明确报告并保留原生上下文，检查结果后可在同一会话继续。用户消息显示独立底色卡片；消息始终按客户端序号排列，运行详情只展示工具调用记录，不展示技能文件正文或工具返回全文。列表固定 SaySo → IM → Web，标题下显示可复制的 Session ID。Web 支持文件/图片上传、拖放和图片粘贴，每条最多 6 个附件、单文件 10 MiB、合计 30 MiB。附件仅存目标客户端并保留历史引用，模型图片通过 CLI 的 image 参数传入。

创建客户端必须选择 Windows/macOS/Linux，绑定与恢复核对系统类型，后续不可更改。设置/修复只展示该系统指引。客户端删除撤销远程访问；项目删除移除登记并解绑渠道，保留工作目录、会话和录音，并保存配置备份。旧客户端未报告 full 权限时，网页明确显示待升级并阻止执行，不能仅凭固定文案宣称已完整授权。

每项目最多一个飞书或钉钉渠道，一个机器人全平台只绑定一个项目。客户端直接连消息平台长连接，AK/SK 只持久存本机。网页和客户端间所有业务经 139 站点、持久 WebSocket 中转，无直连回退。详细关系、工具名称及父子会话管理见 [session-model.md](session-model.md)，协议见 [architecture.md](architecture.md)。

## 数据与恢复基线

服务器持久化账号、设备和验证值、公共项目元数据、机器人指纹归属；不持久化任务正文、录音或 IM Secret。客户端保存配置、项目、Web/IM 历史、原生会话、SaySo 讨论与录音、后台任务状态和通知队列。网页配置 Secret 时会经可信 139 中转，两段 TLS 不等于端到端加密。

升级保留原目录和身份；任务中断后保留提示词、已输出内容及恢复 ID，标记待检查，不自动重复执行。解除 IM 绑定保留历史。SaySo 映射复用旧讨论/录音 ID。配置变更先验证、预占再原子落盘，失败保留原绑定。部署需停止服务备份数据库和凭证目录，程序与数据库成套回滚。

Go 单元/集成测试、JS 语法、浏览器预览、交叉编译、Linux race 和隔离 MSI 验收是代码验证；不能替代真实硬件退出登录、商店显示、真实机器人与真实模型授权的验收。
