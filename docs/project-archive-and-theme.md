# 项目归档与界面主题

项目菜单可归档项目，账号菜单中的“已归档项目”按客户端列出并支持恢复，包括离线客户端。归档状态只存服务器的账号项目目录；客户端心跳保留服务器标记，不要求升级客户端。归档隐藏侧栏项目，不暂停任务、不解绑渠道，也不修改客户端配置、项目 ID、会话原生恢复 ID、工作目录、草稿或录音。当前打开的会话可以继续使用；历史深链接仍可打开归档项目。默认选项目时跳过已归档项目。

界面设置提供明亮/暗黑主题，默认暗黑。选择存当前浏览器的 `localStorage["remote-agent.theme"]`，刷新及同源其他标签页同步；存储不可用时本页仍可切换并明确提示。主题在首屏绘制前应用，工作台及内嵌 SaySo 使用同一选择。

此变更未迁移 Codex 执行协议。当前执行仍用 `codex exec/resume --json`，不是 app-server；项目归档与界面主题不改动 CLI 安装或历史会话文件。未来接入 app-server 需另行验证旧会话恢复、权限和中断语义，不能以 UI 验证代替协议兼容验收。
