# 会话列表的七天隐藏规则

工作台默认把最后消息距今满7×24小时的会话折叠到列表底部“7天前的会话”，展开即可沿用原会话继续。只改变列表显示，不写入归档或删除标记，不迁移历史、附件、草稿、topic映射或原生上下文。Web和IM会话采用同一规则，SaySo入口继续置顶。

运行中、排队中或含待处理队列项的会话继续出现在主列表。打开旧会话或阅读历史不会改变消息时间；新的消息/历史事件到达后，同一个会话自动回到主列表。仅重命名或取消归档不会刷新消息时间。正在查看的旧会话可继续在右侧阅读，即使左侧分组已折叠。

搜索包含旧会话：输入关键词时直接列出匹配项，清除搜索后恢复分组。手动归档仍使用独立“归档”入口。列表计数只包含主列表和SaySo，折叠组另显示本页已加载旧会话数；原“加载更多”继续翻页，不为统计旧会话主动读取全部分页。折叠状态在当前账号/客户端/项目内保留，切换范围或刷新页面重新默认折叠。

每次列表刷新重新计算阈值，同时只有一个本地到期定时器，支持缓存/离线列表跨过七天边界；页面重新可见时也重新计算。此功能不发起额外历史请求、后台高频轮询、模型执行或会话管理操作。

## 消息时间与旧客户端

新版客户端在`sessions.list`及`sessions.get`的会话元数据中返回`lastMessageAt`（Unix毫秒），直接读取现有历史桶末条记录的`createdAt`，涵盖已持久化的用户、agent和运行事件。只取末条，不扫描或转发全部历史，无旧数据迁移；历史读取仍受原客户端和项目鉴权约束。空会话返回0，网页按创建时间折叠；无效或未知时间保守保留在主列表。

旧客户端尚无`lastMessageAt`时，网页兼容使用`updatedAt`，再回退创建时间。因此旧客户端的重命名/归档恢复仍可能暂时让旧会话按近期活动显示；严格按最后消息判断需客户端正常空闲升级到本次runtime。网页发布与已安装客户端生效分别记录，不强制重启活跃客户端。

## 验证

`tools/test-session-recency.cjs`使用模拟账号、客户端和消息，覆盖满七天边界、改名隔离、空/旧/未知时间、运行与待处理队列例外、折叠/搜索/分页、直接阅读保留、新消息恢复、无网络到期、跨账号/客户端状态隔离、桌面和手机。Go测试使用临时数据库验证旧历史读取、重命名不改消息时间、重新打开数据库、追加消息、归档列表及空会话。

```powershell
go test ./internal/agent -run 'Test(SessionLastMessage|EmptySession)' -count=1
$env:PLAYWRIGHT_MODULE=(Resolve-Path .local/compact-ui/node_modules/playwright).Path
node tools/test-session-recency.cjs
```
