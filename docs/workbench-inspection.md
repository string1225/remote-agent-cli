# 工作台运行详情、只读变更与引用

2026-11-09。参考 T3 Code 的运行状态、按需检查和持久接收设计，沿用现有 Go daemon、网页与 139 WebSocket 中转；Codex/Qoder 的选择和原生会话恢复方式不变。

## 已实现

- 会话顶部区分最近任务状态、实际执行耗时、离线缓存与历史同步状态。执行时间由客户端持久的 `taskStartedAt/taskCompletedAt` 计算；排队时间单独计算。离线时标明上次状态。同步失败不会伪装成连接重试。
- “运行详情”按工具 ID 合并开始和完成事件，展示名称、状态、耗时及执行计划。仅保留有界元数据，命令只保留第一行；不保存或展示输入参数、工具返回正文和 reasoning。缺少完成事件的调用标为状态未确认，不能宣称成功。旧历史继续显示原有工具摘要。
- “工作区变更”按需查询当前项目的 Git 状态，选择文件后读取暂存区、工作区或未跟踪文件内容。它表示共享目录的全部未提交变更，不能作为某一轮独占修改的证明。无切分支、暂存、提交、恢复或 fetch 操作；预览禁用外部 diff、textconv 和 clean/process 等 Git 过滤器。仅显示授权项目内的变更文件，最多 200 项、每段预览 128 KiB；目录、二进制和被截取的内容有明确说明。
- 回答的“引用”把选中文字或回答正文和来源会话、轮次加入当前草稿；“引用会话”读取同项目已加载会话的最近历史页，添加有界文字摘录和链接。不发送任务，保留原草稿与附件。跨执行器原生上下文迁移、自动读取其他设备的会话不在本次范围。
- “子任务”按需列出当前客户端上由本会话直接创建的子会话，可打开原会话。跨客户端的管家派工仍以现有结果卡展示。
- “连接检查”提供版本、平台、执行器可用性、活动任务数和同步状态。复制内容不包含聊天正文、草稿、工具返回或凭据。

## 协议与兼容

`authenticate/services.list` 新增 `runActivities`、`workspaceReview`、`workbenchDiagnostics` 标记。新网页遇到旧客户端隐藏相应远端检查入口；本地引用和连接状态仍可用。`ChatEntry.activity` 及会话时间戳为可选字段，不迁移或覆盖旧数据库。

| 请求 | 参数与行为 |
| --- | --- |
| `workspace.changes` | `serviceId`，仅返回项目内 Git 变更路径与索引/工作区状态 |
| `workspace.diff` | `serviceId/path`，路径须精确匹配当前变更列表，无路径通配符 |
| `sessions.children` | `serviceId/sessionId/cursor`，校验父会话项目归属后分页列出本机直接子会话 |
| `diagnostics.snapshot` | 只返回脱敏客户端状态，不接触模型或机器人 |

检查请求继续使用已认证的 139 中转，客户端检查拥有 12 秒总时限。网页每 4 秒的列表和增量历史轮询、最近历史窗口、按需旧历史分页保持兼容；新界面不另建历史轮询。切换账号、客户端、项目或会话后关闭检查面板；迟到响应不能写入新页面或草稿。

## 持久接收和恢复

派生新会话的任务将会话、首条消息、幂等请求回执和队列记录写入同一 bbolt 事务。确认返回后再由已有 daemon worker 执行。队列已满时先拒绝，不产生只有会话或回执的半成品。任务开始和结束时，队列状态与会话状态分别在同一事务中更新；保存失败不能作为成功回报给调用方。

重启仍保留原会话、原生恢复 ID、消息、录音、附件与排队内容。中断任务需人工检查后继续，未执行消息保持暂停，不自动重放。上线前沿用现有服务端与 runtime 发布流程备份并准备回滚；旧程序可忽略新增 JSON 字段。涉及原生 CLI、真实机器人、MSI/SCM 生命周期仍需对应目标环境验收。

## 验证

Go 测试覆盖事务失败回滚、接收去重、工具元数据脱敏、Git 索引不变、暂存和未暂存差异、精确路径、子目录隔离和预览上限。`node tools/test-workbench.cjs` 使用模拟凭据及消息，覆盖桌面/手机、草稿引用、差异文本不可执行、迟到响应和离线检查。它们不发送真实机器人消息或修改真实客户端绑定。
