BRING A DEVICE ONLINE

添加一台设备

在目标电脑的终端中运行对应命令。它会安装 本地 CLI、绑定设备，并按服务器设置安装和配置 Codex。

一次性安装凭证 · 15 分钟有效 · 请勿分享

Windows 使用 MSI + Windows Service，开机自动启动，退出登录后保持在线，不依赖计划任务。macOS 需要保持登录。Linux 使用 systemd 用户服务；启用 linger 后可在退出登录后继续运行并开机启动。 如只需要本地配置，请使用「Codex 接入与帮助」里的本地 CLI 安装命令。 Windows 安装命令末尾加 -NoStart，macOS / Linux 改用 bash -s -- --no-start，可只绑定而不启动远程服务。

CODEX / YOUR WORKSPACE

Codex 服务中心

安装客户端，接入你的工作设备

远程客户端通过长连接 WebSocket 接入当前站点。网页任务、会话和 SaySo 数据均由站点中转，任务在你的电脑执行。

远程客户端安装与升级

已有设备：重新执行原绑定安装命令即可升级，保留设备配置、项目、会话和 SaySo 录音。Windows 的 EXE update 不适用于 MSI 安装。

仅使用 Codex 代理

以下命令安装独立的本地 CLI；无需绑定设备，也不会启动远程服务。

  1. 运行安装命令，然后打开新终端。
  2. 在「我的 Token」创建代理 Token，复制生成的一键配置命令。
  3. 命令会补装缺少的 Codex CLI，备份并更新 TOML。重启 Codex App，新建本地会话即可使用。
  4. 需要远程任务时，在工作台添加设备、运行绑定命令，再连接设备并添加项目。

本地 CLI 命令

安装目录：Windows %USERPROFILE%\.remote-agent\bin；macOS / Linux ~/.remote-agent/bin。脚本将它加入用户 PATH。

配置文件、备份和恢复

使用 CODEX_HOME 指定的目录，默认 ~/.codex/config.toml。修改前在同目录创建 config.toml.backup-*，保留模型、项目和其他 provider 设置。凭据只保存在受保护的本机配置内。恢复时先退出 Codex 和远程任务，再用对应备份替换 config.toml。

Codex App、旧会话和官方账号功能

代理承接模型调用。桌面端的账号资料、云端任务和插件仍使用官方服务。更新配置后请完全退出并重新打开 App，先新建本地会话验证；旧会话可能保留原来的 provider。不要用旧连接助手的「更新配置」覆盖这里生成的配置。

Windows App 安装与升级会打开 Microsoft Store 产品页面，由当前登录用户完成；macOS 使用 Homebrew 的 codex-app。若 App 通过其他渠道安装，请使用其内置更新或官方安装器。

只绑定、不启动；启动和停止远程 Agent

本地 CLI 安装入口不创建远程连接。绑定安装器默认启用远程服务；Windows 可在安装命令末尾添加 -NoStart，macOS / Linux 将末尾的 bash 改为 bash -s -- --no-start。以后使用 remote-agent start 启用自启动并连接，remote-agent stop 停止并禁用自启动；设备绑定和历史保留。Windows MSI 的启停和服务配置需要管理员权限，由 Windows Service 维持进程。Linux 启动服务需要 systemd 用户会话。
