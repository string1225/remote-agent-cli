CODEX / YOUR WORKSPACE

Codex 服务中心

安装客户端，接入你的工作设备

先安装客户端，再把电脑绑定到当前账号。项目任务在你的电脑执行，会话和录音保存在设备上。

远程客户端安装与升级

Windows 首次安装 MSI 并配置服务；日常执行 remote-agent update 更新业务程序，无需重复安装或授权。原设备绑定、项目、会话和录音保留。

绑定后，启动 Codex

设备绑定会自动申请当前账号的 Token。再次刷新时，使用本机绑定识别所属账号。

  1. 安装客户端。Windows 下载 MSI；macOS / Linux 使用设备绑定页上的安装命令。
  2. 在当前账号下添加设备，将绑定命令复制到这台电脑执行。设备会自动申请所属账号的 Token，并备份和更新配置。
  3. 终端会显示 Token 所属的平台账号。运行 remote-agent codex setup 可刷新配置并补装缺少的 Codex CLI，再运行 codex，或重启 Codex App 并新建本地会话。
  4. 在左侧客户端添加项目，会自动打开一个新的 Web 会话。

本地 CLI 命令

Windows 程序安装到 %ProgramFiles%\Remote Agent，由 MSI 加入系统 PATH；用户数据继续保存在原目录。macOS / Linux 程序位于 ~/.remote-agent/bin。

配置文件、备份和恢复

使用 CODEX_HOME 指定的目录，默认 ~/.codex/config.toml。修改前在同目录创建 config.toml.backup-*，保留模型、项目和其他 provider 设置。凭据只保存在受保护的本机配置内。恢复时先退出 Codex 和远程任务，再用对应备份替换 config.toml。

Codex App、旧会话和官方账号功能

代理承接模型调用。桌面端的账号资料、云端任务和插件仍使用官方服务。更新配置后请完全退出并重新打开 App，先新建本地会话验证；旧会话可能保留原来的 provider。不要用旧连接助手的「更新配置」覆盖这里生成的配置。

Windows App 安装与升级会打开 Microsoft Store 产品页面，由当前登录用户完成；macOS 使用 Homebrew 的 codex-app。若 App 通过其他渠道安装，请使用其内置更新或官方安装器。

只绑定、不启动；启动和停止远程 Agent

Windows MSI 安装自动服务；未绑定时服务等待本机配置。remote-agent connect 绑定并配置服务，可加 --no-start 暂不连接。Codex Token 配置不会创建远程绑定。以后使用 remote-agent start / stop 控制服务；绑定和历史保留。Windows 服务配置需要管理员授权，由 Windows Service 维持进程。Linux 启动服务需要 systemd 用户会话。

客户端、项目与三类会话如何协作

客户端是一台设备；项目是工作目录与 Codex / Qoder 执行器。每个项目固定置顶一个 SaySo 入口，并可绑定一个飞书/钉钉渠道会话，其余为 Web 会话。SaySo Action 和渠道助理可以创建新的 Web 会话来执行工作；Web 会话可通过客户端工具查询同账号其他客户端/项目、发起跨设备任务，并通知项目的 IM 渠道。
