# Operating-system logos

Windows 11, Apple and Linux SVGs from Devicon v2.17.0, MIT (see LICENSE).
https://github.com/devicons/devicon/tree/v2.17.0/icons

Dark-theme Apple and Linux variants use a light fill. macos-dark.svg reuses the
existing Apple path; linux-dark.svg uses Devicon v2.17.0 linux-plain.svg
(Git blob 26ced8fd138caa307d27cfa4acecdf0a707defc3), whose simpler silhouette is
clearer at the sidebar's 18px size. The original light-theme assets are retained.

Logos identify the operating system; their respective trademarks belong to their owners.
