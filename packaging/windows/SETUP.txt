Remote Agent for Windows

1. Download and install the x64 or ARM64 MSI. No installation script is needed.
   The installer adds Program Files\Remote Agent to the machine PATH and installs
   the automatic RemoteAgent Windows Service. It runs after logout.
2. The completion window stays open and displays the following commands.
   Open a new PowerShell (restart Windows Terminal completely if it was open):

   remote-agent version
   remote-agent codex setup --server https://codex.sunny-string.cn/agents --token-prompt

   Paste a personal model Token when prompted. Input is hidden; no secret is
   passed to MSI, UAC arguments or command history.
3. Remote access is optional. Add a client on the website, then use its generated
   device binding command, or prompt for the one-time device token:

   remote-agent connect --server https://codex.sunny-string.cn/agents --token-prompt

   connect captures the original user's tool environment, then requests admin
   approval to configure the existing service. Existing bindings are preserved.

Upgrades: download and install a newer MSI. The installer removes obsolete
Remote Agent program copies and exactly matching legacy startup tasks only
after successful commit. Device identity, config, projects, history.db, SaySo
recordings, Codex/Qoder programs and their own settings remain in place.

The service runs as LocalService with its own SID. Credentials remain in the
original private user directory. The ProgramData service profile contains paths
and tool environment only. service status shows service configuration;
start/stop and configuration require an administrator.

Uninstall removes service/programs and this installer's PATH entry. It retains
business data and the protected service profile. Failed upgrades roll back the
program installation and do not run legacy program cleanup.
