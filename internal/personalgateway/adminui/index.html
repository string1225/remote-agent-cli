怎么在其他电脑上使用？

在下方复制配置，将设备 Token 保存为该电脑的 SUNNY_CODEX_TOKEN 环境变量，再重启 Codex CLI。每台电脑使用各自的 Token，所有设备共用服务器登录账号的额度。

model = "gpt-6-sol"
model_provider = "sunny_personal"

[model_providers.sunny_personal]
name = "Sunny Personal"
base_url = "https://codex.sunny-string.cn/openai/personal/v1"
wire_api = "responses"
env_key = "SUNNY_CODEX_TOKEN"
requires_openai_auth = false
supports_websockets = false

在用户目录的 .codex/config.toml 中合并配置，替换已有的 model 和 model_provider，避免重复声明。此模式无需启动本站连接助手。模型范围以服务器账号为准；ChatGPT 网页、云端会话及连接器登录需分别处理。
